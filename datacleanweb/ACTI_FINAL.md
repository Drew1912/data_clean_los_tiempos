## VALIDACIÓN Y CONTROL DE CALIDAD DEL SISTEMA INFORMÁTICO

**Actividad Práctica de Cierre**

## PROPÓSITO DE LA ACTIVIDAD

Verificar que el sistema informático desarrollado por cada grupo cumpla los objetivos del proyecto, funcione correctamente, sea fácil de utilizar y cuente con la documentación necesaria para su entrega y defensa final.

## 1. ACTIVIDADES QUE DEBEN REALIZAR

### Actividad 1. Auditoría de funcionalidades del sistema

Revisen todas las funciones implementadas y comprueben su funcionamiento. Consideren, según corresponda:

- Inicio de sesión y control de usuarios.
- Registro de información.
- Modificación y actualización de registros.
- Eliminación de registros.
- Búsquedas y consultas.
- Generación de reportes.
- Conexión y operaciones con la base de datos.

### Actividad 2. Pruebas de funcionamiento

Ejecuten cada función con datos de prueba y comparen el resultado esperado con el resultado obtenido. Registren evidencias cuando sea posible.

| Funcionalidad | Resultado esperado | Resultado obtenido | Estado |
| --- | --- | --- | --- |
| Inicio de sesión | Permitir el acceso autorizado. |  |  |
| Registro | Guardar la información ingresada. |  |  |
| Modificación | Actualizar los datos seleccionados. |  |  |
| Eliminación | Eliminar el registro seleccionado. |  |  |
| Reportes | Mostrar información correcta y completa. |  |  |
| Base de datos | Almacenar y recuperar datos correctamente. |  |  |

**Estados posibles:** Correcto / Incorrecto / Requiere ajustes.

### Actividad 3. Evaluación de la experiencia del usuario

Revisen el sistema desde la perspectiva de una persona que lo utilizará. Respondan:

- ¿El sistema es fácil de utilizar?
- ¿Los botones, menús y opciones son comprensibles?
- ¿La información está organizada y es legible?
- ¿Los mensajes de error orientan al usuario?
- ¿La navegación entre pantallas es sencilla?
- ¿El diseño mantiene uniformidad en colores, tipografía y distribución?

**Producto a entregar:** listado de mejoras realizadas y aspectos pendientes.

### Actividad 4. Preparación de la documentación técnica

Verifiquen que el grupo dispone de los siguientes documentos y recursos:

| Elemento | Contenido que deben presentar | Verificado |
| --- | --- | --- |
| Manual de usuario | Instrucciones para utilizar el sistema. | ☐ Sí ☐ No |
| Manual técnico | Tecnologías, arquitectura y estructura del sistema. | ☐ Sí ☐ No |
| Base de datos | Modelo, relaciones y estructura de las tablas. | ☐ Sí ☐ No |
| Código fuente | Archivos organizados del sistema desarrollado. | ☐ Sí ☐ No |
| Instalación | Pasos y requisitos para ejecutar el sistema. | ☐ Sí ☐ No |
| Credenciales | Accesos de demostración controlados; no incluir contraseñas personales. | ☐ Sí ☐ No |

### Actividad 5. Simulacro de exposición final

Preparen una exposición breve y realicen una demostración práctica del sistema. Todos los integrantes deben conocer el proyecto y su funcionamiento.

1. ¿Qué problema identificaron en la empresa?
2. ¿Qué solución desarrollaron?
3. ¿Qué funcionalidades tiene el sistema?
4. ¿Qué tecnologías utilizaron y por qué?
5. ¿Cómo funciona el sistema? Demuestren sus principales procesos.
6. ¿Qué resultados obtuvieron?
7. ¿Qué dificultades encontraron durante el desarrollo?
8. ¿Qué mejoras recomendarían para una siguiente versión?
