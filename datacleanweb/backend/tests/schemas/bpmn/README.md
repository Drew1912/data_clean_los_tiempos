# Esquemas BPMN 2.0 de OMG

Archivos de referencia descargados sin modificaciones desde `https://www.omg.org/spec/BPMN/20100501/`: BPMN20.xsd, BPMNDI.xsd, DC.xsd, DI.xsd y Semantic.xsd. Se incluyen para validación XML local reproducible con lxml, sin red al ejecutar tests. Procedencia y términos: [especificación oficial de OMG](https://www.omg.org/spec/BPMN/2.0/).

Son esquemas de un estándar, no datos empresariales ni componentes de aplicación. XSD válido no acredita ejecución de proceso ni revisión en la interfaz de Camunda.
